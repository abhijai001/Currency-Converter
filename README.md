# 💱 Currency Converter

A simple and responsive **Currency Converter** built using HTML, CSS, and JavaScript.

This project allows users to enter an amount, select the currencies they want to convert between, and get the latest exchange rate using the **Frankfurter API**.

## 🚀 Live Demo

🔗 [Currency Converter](https://abhijai001.github.io/Currency-Converter/)

## 📸 Preview

A clean and simple interface for converting currencies with dynamically updated country flags and exchange rates.

## ✨ Features

- 💰 Convert currencies in real time
- 🌍 Support for multiple currencies
- 🚩 Automatically updates currency flags
- 🔄 Select both source and target currencies
- ⚡ Fetch exchange rates using JavaScript `fetch()`
- 📱 Responsive and simple user interface
- ❌ Basic error handling for failed API requests

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript (ES6+)** – Application logic and API integration
- **Fetch API** – Fetching exchange-rate data
- **Frankfurter API** – Currency exchange-rate data
- **FlagsAPI** – Currency/country flag images
- **Font Awesome** – Icons
